## 2. Scope (this wave)

### A. Tech debt & forensic bugs
- **A1 — `db_path` normalization (P1).** Every `database.py` function currently binds
  `db_path=DB_NAME` at definition time, so reassigning `database.DB_NAME` is ignored by all but the
  4 newest helpers. Convert every function to `db_path=None` + `db_path = db_path or DB_NAME` at the
  top. Removes a latent footgun; makes the whole layer overridable.
- **A2 — Same-column drag off-by-one (P2 bug).** `TaskListArea.dropEvent` includes the hidden
  dragged card in the drop-index calculation. `handle_task_drop` computes the target list with the
  moved card removed, so the index space is mismatched → off-by-one when dropping below the original
  slot. Fix: exclude the dragged card (match by `task_id`) and compute the insertion index in the
  space of non-dragged cards.
- **A3 — `TaskListArea.layout` shadows `QWidget.layout()` (P2).** Rename the attribute to
  `list_layout` in `widgets.py` (and its two references in `ColumnWidget`).
- **A4 — Dead `#TaskCardDueDate` object name (P3).** The due-date label is styled inline; its
  object name has no QSS rule. Remove the dead `setObjectName`.
- **A5 — iCalendar line folding off-by-one (P3).** Continuation lines can be 1 octet over the
  75-octet limit because the leading continuation space isn't counted. Continuation pieces must be
  ≤74 content octets.

### B. Features
- **B1 — Automatic DB backups on startup.** New `backups.py`: `backup_database(db_path, keep=5,
  backup_dir=None)` makes a consistent SQLite `.backup()` copy into a `backups/` folder as
  `ekin_board.db.<YYYYMMDD_HHMMSS_ffffff>.bak`, rotating to the `keep` most recent. Wired into
  `MainWindow.__init__` **before** `init_db()` (so we snapshot pre-migration). No-op on first run
  (DB doesn't exist yet).
- **B2 — Overdue tasks in the bell.** The deadline bell currently shows only today/tomorrow. Add an
  **"ATRASADAS"** group (danger-styled) at the top of `NotificationsPopup` for tasks with
  `due_date < today`, include them in the badge count. Implemented by querying
  `get_scheduled_tasks(end_date=tomorrow)` (which returns overdue + today + tomorrow) and splitting
  three ways in the popup.
- **B3 — "Subscribe in Google" helper in Ajustes.** In `CalendarSettingsDialog`, add a field for the
  **public feed URL** (new `app_settings` key `ics_public_url`) and a **"Suscribirse en Google"**
  button that saves + copies the URL to the clipboard and opens Google's *add-by-URL* settings page
  (`https://calendar.google.com/calendar/u/0/r/settings/addbyurl`) — automating the manual step
  users trip on.
- **B4 — Calendar drag-to-reschedule.** Calendar chips become draggable; `DayCell` accepts drops and
  the view updates the task's `due_date` via a new focused DB helper
  `update_task_due_date(task_id, due_date, db_path)`, then refreshes and signals the app so the
  bell/`.ics` stay in sync.

### C. Testing
- **C1 —** `tests/test_ics_export.py`: `_escape`, `_fold_line` (≤75 octets incl. continuation
  space, no multibyte split), `_sequence_and_modified`, and `build_ics` (VCALENDAR/VEVENT, all-day

- **C2 —** `tests/test_backups.py`: creates a backup, rotates to `keep`, backup is a valid DB with

- **C3 —** extend `tests/test_database.py`: `update_task_due_date`, and a test proving the

  explicit `db_path` hits the new DB).

## 3. Design details & contracts

### A1 — `db_path` normalization
- `get_connection` and `init_db` keep working defaults but move to `db_path=None` → `db_path or
  DB_NAME` for consistency (they're called with explicit paths in tests, so behavior is unchanged).
- Every CRUD/query function: signature `..., db_path=None`; first body line resolves
  `db_path = db_path or DB_NAME`. **Positional callers unaffected** (tests pass `db_path` positionally
  in some places, e.g. `get_board(board_id, db_path)`, `get_task_tags(task_id, db_path)`, and by
  keyword elsewhere — both keep working because the parameter stays in the same position).
- Acceptance: full existing suite stays green; new C3 override test passes.

### A2 — drop-index fix (`widgets.py :: TaskListArea.dropEvent`)
```
cards = [itemAt(i).widget() for i in range(list_layout.count())]
cards = [w for w in cards if isinstance(w, TaskCard) and w.task_id != dragged_id]
target_pos = len(cards)
for idx, w in enumerate(cards):
    if drop_y < w.y() + w.height()/2:
        target_pos = idx; break
```
Matches `handle_task_drop`, which removes the moved task before inserting at `target_pos`. Cross-column
drops are unaffected (dragged card isn't in the target area).

### A5 — `_fold_line`
First physical line ≤75 octets; after the first cut, `limit = 74` so each continuation (`"\r\n " +
piece`) is ≤75 octets. Preserve the existing UTF-8 boundary guard.

### B1 — `backups.py`
```
backup_database(db_path, keep=5, backup_dir=None) -> str | None
```
- Returns `None` if `db_path` doesn't exist.
- `backup_dir` defaults to `<dir(db_path)>/backups`; created if missing.
- Filename `ekin_board.db.<YYYYMMDD_HHMMSS_ffffff>.bak` (microseconds → collision-free, sortable).
- Consistent copy via `sqlite3.connect(db).backup(sqlite3.connect(dest))`.
- `_prune_backups` keeps the newest `keep` (lexicographic == chronological), best-effort removal.

### B4 — reschedule flow
- `CalendarChip` (draggable QPushButton subclass) encodes `application/x-ekin-cal-task-id`.
- `DayCell` gains `setAcceptDrops(True)`, knows its own `date`, emits
  `task_rescheduled(task_id, iso_date)`; only real day cells accept drops.
- `CalendarViewWidget` handles it → `database.update_task_due_date(...)` → `refresh()` + emits
  `data_changed` (new signal) so `MainWindow` can refresh the bell and re-sync the `.ics`.
